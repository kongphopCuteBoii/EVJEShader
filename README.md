# Enhanced Visuals Shader — Crystaline

[🇬🇧 English](README.md) · [🇹🇭 ภาษาไทย](README.th.md)

**Crystaline** is a Minecraft Java Edition shader project developed from scratch, exploring real-time rendering, visual presentation, and performance-conscious graphics programming.

The project focuses on creating an atmospheric visual experience while working within the constraints of rasterization and real-time performance. Rather than pursuing realism at all costs, Crystaline explores how lighting, color, atmosphere, and other rendering techniques can shape the way a world *feels*.

## Goals

- Achieving maximum visual fidelity within the bounds of acceptable performance.
- Pursuing non-photorealistic graphics with an artist-centric philosophy in mind.
- Approaching shader development differently by applying the same philosophy from my Bedrock shader experience.

## Development

Crystaline is an ongoing personal project. Features and rendering techniques are developed, tested in-game, and refined incrementally.

- **Platform:** Minecraft Java Edition
- **Graphics programming:** GLSL
- **Project status:** Work in progress

## Future Plans

The project will continue to evolve as rendering techniques are explored and performance is improved. A Bedrock Edition counterpart, **Cerulean**, is also planned.
