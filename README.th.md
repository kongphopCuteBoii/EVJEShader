# Enhanced Visuals Shader — Crystaline

[🇬🇧 English](README.md) · [🇹🇭 ภาษาไทย](README.th.md)

**Crystaline** เป็นโปรเจกต์ Shader บน Minecraft Java Edition ที่ผมเขียนขึ้นเองทั้งหมดโดยไม่ได้ branch มาจาก shader ไหน ทุกอย่างตั้งแต่ 0 ถูกเขียนขึ้นด้วยตัวผมเอง เพื่อที่จะเขียน shader ที่ภาพสวยแต่บีบเค้น performance สูงสุดบน technical debt ที่น้อยที่สุดเท่าที่จะทำได้ ซึ่งเป็นวิธีการทำงานที่แตกต่างจาก  shader ส่วนใหญ่ที่มีสไตล์ศิลป์เดียวกัน

โปรเจกต์นี้มุ่งสร้างประสบการณ์ภาพที่มีบรรยากาศเฉพาะตัว ภายใต้ข้อจำกัดของการเรนเดอร์แบบ Rasterization เท่านั้น (เพื่อ performance สูงสุด) โดยไม่ละทั้งสไตล์งานศิลป์ที่ตั้งใจไว้
Crystaline ปรับแต่งสี แสง บรรยากาศ เพื่อให้ได้มาซึ่งผลลัพธ์ที่แตกต่าง และถามว่า "องค์ประกอบทางทัศนศิลป์ในเกม สามารถเปลี่ยนความรู้สึกที่ผู้เล่นมีต่อโลกในเกมได้อย่างไรบ้าง?"

## เป้าหมาย

- สร้างสรรค์ภาพที่สวยที่สุด  โดยใช้ hardware อย่างคุ้มค่าที่สุด
- สร้างภาพที่ไม่สมจริงจนเกินไป เพื่อเหลือพื้นที่ไว้สำหรับความหลากหลายทางทัศนศิลป์
- การใช้ประสบการณ์จากการทำ shader บน Minecraft Bedrock มาปรับใช้ในด้าน performance

## การพัฒนา

Crystaline ยังอยู่ระหว่างการพัฒนา โดยมีการทดลองเทคนิคการเรนเดอร์ ทดสอบภายในเกม และปรับปรุงแก้ไขอยู่เรื่อย ๆ

- **แพลตฟอร์ม:** Minecraft Java Edition
- **ภาษาสำหรับเขียนโปรแกรมกราฟิก:** GLSL
- **สถานะโปรเจกต์:** Work In Progress (W.I.P.)
